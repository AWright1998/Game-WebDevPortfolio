Project Overview

A browser-based wrestling booking simulator built to demonstrate both web development and game systems design.

RingMaster Booker lets players create a wrestling promotion, sign wrestlers, manage a roster, create championships, build rivalries, simulate matches, generate ticket revenue, track rankings, handle injuries, and save or load progress.

I built this project to combine my interest in professional wrestling with my background in computer games development and web development. It acts as a portfolio piece showing that I can design interconnected gameplay systems outside of Unity as well as build interactive front-end applications.

Core Features

The project includes multiple systems designed to work together as a small management game loop.

Roster

Wrestler Management

Players can sign wrestlers with stats including popularity, stamina, morale, momentum, mic skill, charisma, in-ring skill, role, style, gender, and contract cost.

Matches

Match Simulation

Match winners are calculated using weighted random logic based on wrestler stats, momentum, match type, championship stakes, and rivalry heat.

Business

Promotion Finances

The simulator tracks promotion budget, fans, attendance, ticket price, ticket revenue, contract costs, and fan changes after each match.

Gameplay Systems

The main goal was to make the systems connect together rather than exist as separate features.

Implemented Systems

  • Promotion creation and naming
  • Roster management
  • Wrestler profile cards and stat bars
  • Weighted match simulation
  • Multiple match types
  • Championships and title matches
  • Rivalries with heat values
  • Injury risk and recovery
  • Advance week system
  • Fan growth and loss
  • Attendance and ticket revenue
  • News feed generation
  • Power rankings
  • Save/load using LocalStorage

Core Game Loop

The player signs wrestlers, spends budget, creates rivalries, books matches, gains or loses fans, earns ticket revenue, manages injuries, and advances the promotion over time.

This creates a foundation for a larger wrestling management game where decisions have visible consequences.

Technical Approach

The project was built as a React application with reusable components and persistent browser saves.

React

Component Structure

The UI is split into components including roster cards, wrestler profiles, match booking, championships, rivalries, rankings, news feed, save/load, and advance week.

Logic

Simulation Design

Match results are calculated using weighted random values and bonuses from wrestler stats, rivalry heat, match type, championship stakes, and momentum.

Save

Persistent Data

LocalStorage is used to save promotion data, wrestlers, championships, and player progress between browser sessions.

Design Challenges

The biggest challenge was connecting systems so they felt like part of one management game.

The project needed more than simple roster management. I wanted each feature to affect another part of the simulation. For example, match quality affects fan growth, fans affect attendance, attendance creates revenue, and revenue affects future roster decisions.

I also added risk and reward through match types and injury chances. Bigger matches can produce stronger ratings, but also create a higher chance of injuries, forcing the player to think about booking decisions.
